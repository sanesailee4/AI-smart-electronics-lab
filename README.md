# AI-smart-electronics-lab

VOLTIQ is an AI-powered IoT-based smart energy monitoring system developed using ESP32, SCT-013 current sensors, ZMPT101B voltage sensor, relays, Firebase, and a React dashboard. The system continuously monitors voltage, current, and power consumption across multiple channels in real time.
It provides overload protection by automatically cutting off the relay when power exceeds safe limits and generates intelligent alerts using a lightweight AI-based prediction model. The project also includes live graphs, channel-wise energy billing, remote relay control, and mobile-friendly monitoring through a responsive web dashboard.
This system enhances traditional electrical protection by combining real-time monitoring, predictive analysis, remote accessibility, and smart automation for safer and efficient energy management
